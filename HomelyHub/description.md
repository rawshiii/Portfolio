Developed a full-stack hotel booking web application using the MERN stack (MongoDB, Express.js, React.js, and Node.js). 
The platform allows users to browse hotels, view room details, check availability, and make bookings through an interactive and responsive interface. 
Implemented secure user authentication, booking management, search and filter functionality, and admin features for managing hotels and reservations. 
Integrated REST APIs for smooth frontend-backend communication and used MongoDB for efficient data storage. 
Focused on creating a user-friendly UI, responsive design, and seamless booking experience.
