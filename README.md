# HomelyHub 🏨

A full-stack hotel booking platform built using the MERN Stack that allows users to browse hotels, view details, and make bookings through a modern and responsive interface.

## Features

* User Authentication
* Hotel Listing & Search
* Hotel Details Page
* Hotel Booking System
* Responsive User Interface
* Protected Routes
* REST API Integration
* MongoDB Database Integration

## Tech Stack

### Frontend

* React.js
* React Router
* Axios
* CSS / Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## Project Structure

```txt
backend/
frontend/
```

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
